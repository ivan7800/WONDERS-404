MANUAL DE EXPLORACIÓN

Descubre París
a tu ritmo.

Arrastra con el ratón o con el dedo para rotar la escena. Utiliza la rueda del ratón o el gesto de pellizcar para acercarte y alejarte. Selecciona niveles para cambiar el punto de interés.

En ASCENSOR subes desde la base hasta la cima, MIRADOR te sitúa junto a la plataforma seleccionada y VISITA GUIADA recorre los tres niveles. DETENER cancela la animación. También puedes cambiar la atmósfera, controlar la exposición, activar destellos nocturnos (el sonido aún no está disponible en WebGL). MODO FOTO oculta la interfaz: guarda una captura o pulsa Escape para salir. Atajos: P fotografía, 1–4 niveles, D día, N noche, O ocaso.
