# Preparación del repositorio en GitHub

Valores recomendados para configurar la página About al preparar una publicación:

- **Description:** Interactive stylized 3D Eiffel Tower and Paris experience built with local WebGL and Canvas fallback.
- **Topics:** `eiffel-tower`, `paris`, `webgl`, `3d`, `canvas`, `javascript`, `github-pages`, `interactive-experience`
- **Homepage:** `https://ivan7800.github.io/EIFFEL-404/`

El proyecto no incluye una licencia porque el autor todavía no ha seleccionado condiciones de reutilización. La visibilidad pública del repositorio no equivale a conceder una licencia abierta. Elige una licencia antes de invitar a reutilizar o contribuir al código.

La workflow `.github/workflows/quality.yml` valida cambios; no publica automáticamente GitHub Pages. Mantén el mecanismo de publicación ya configurado hasta probar la candidata.
